## 小标题

今天我终于把自己的 Hexo 博客搭建好，并成功部署到华为云服务器上了！不仅如此，为了防止恶意脚本刷接口，我还顺手做了一套完整的自动防御系统。

<!-- more -->

### 日常发布流程

每次在本地写完新文章，只需要在博客根目录执行以下两条命令，就能一键发布到线上：

```bash
# 生成静态文件
npx hexo generate

# 将生成的文件推送到服务器指定目录
scp -r public/* root@x.x.x.x:/var/www/my-blog/



### 服务器防御配置踩坑

为了保障博客安全，我在 Nginx 配置了限速，防止恶意并发请求：

```nginx
# Nginx 限速配置：每秒允许10个请求，允许突发30个
limit_req_zone $binary_remote_addr zone=blog_limit:10m rate=10r/s;
limit_req zone=blog_limit burst=30 nodelay;
```

光有限速还不够，如果对方一直换 IP 刷，依然会消耗资源。所以我又配合 Fail2ban 做了自动封禁：

```ini
# Fail2ban 抓人规则
maxretry = 5    # 60秒内触发5次错误
findtime = 60   # 观察期60秒
bantime = 3600  # 封禁1小时
```

由于测试心切，我用脚本给自己服务器发了 50 个并发请求，结果瞬间触发了 Nginx 的限速，紧接着就被 Fail2ban 直接拉黑，连 SSH 都连不上了。最后只好用手机热点开 VNC 控制台，执行解封命令才把自己“救”出来：

```bash
# 把自己从小黑屋里放出来
fail2ban-client set nginx-limit unbanip 我的IP
```

这里的内容在首页会被折叠，需要点“阅读全文”才看得到。以后我会在这里记录更多折腾日常！

### 后续操作步骤：

1. 在终端里粘贴保存后，运行：
   ```bash
   npx hexo clean && npx hexo generate
   ```
2. 上传到服务器：
   ```bash
   scp -r public/* root@x.x.x.x:/var/www/my-blog/
   ```
3. 打开浏览器刷新 `https://x.x.x.x`。

去网页上看看效果吧！用代码块包起来的内容，在网页上会显示出漂亮的背景和高亮，读起来非常专业。
